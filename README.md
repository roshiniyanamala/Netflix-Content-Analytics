# Netflix Content Analytics

## Project Overview

An end-to-end data analytics project focused on exploring Netflix movies and TV shows to identify content distribution patterns, genre trends, ratings, and country-wise insights. The project combines Python-based exploratory data analysis, SQL-based business analysis, and an interactive Power BI dashboard to support data-driven content strategy decisions.

## Objectives

* Analyze the distribution of movies and TV shows.
* Identify trends in content ratings, genres, and release years.
* Explore country-wise content distribution.
* Analyze content additions over time.
* Answer business questions using SQL queries.
* Build an interactive Power BI dashboard.
* Generate actionable business insights and recommendations.

## Tools & Technologies

* **Python:** Exploratory data analysis and data processing
* **Pandas:** Data manipulation and cleaning
* **Matplotlib & Seaborn:** Data visualization
* **SQL:** Business queries, aggregations, and trend analysis
* **Power BI:** Interactive dashboards and KPI reporting
* **Jupyter Notebook:** Python analysis environment

## Dataset

The dataset contains Netflix titles and attributes such as:

* Show ID and title
* Content type (Movie or TV Show)
* Director and cast
* Country
* Date added
* Release year
* Rating
* Duration
* Genre
* Description

**Dataset source:** https://www.kaggle.com/datasets/shivamb/netflix-shows

## Project Workflow

1. Load and validate the dataset.
2. Clean and prepare the data using Python.
3. Perform exploratory data analysis and visualization.
4. Use SQL to answer business questions.
5. Develop an interactive dashboard in Power BI.
6. Summarize key findings and business recommendations.

## Key Analysis Areas

* Movie vs. TV Show distribution
* Content ratings
* Release-year trends
* Country-wise content distribution
* Genre analysis
* Content added over time
* Movie duration and TV show seasons

## SQL Business Questions

* How many movies and TV shows are in the catalog?
* Which countries contribute the most titles?
* Which genres appear most frequently?
* What are the most common content ratings?
* How has the content catalog changed over time?
* How do movie and TV show distributions vary by country?

## Power BI Dashboard

The planned interactive dashboard will include:

* KPI cards for total titles, movies, and TV shows
* Content type and rating distribution
* Country-wise and genre-wise analysis
* Content release and addition trends
* Slicers for content type, country, rating, and release year

## Business Value

The project aims to transform Netflix catalog data into understandable insights that can support content acquisition, programming strategy, and data-informed decision-making.
